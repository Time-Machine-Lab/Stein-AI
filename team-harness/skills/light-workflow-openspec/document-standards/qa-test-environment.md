# QA Test Environment 文档规范

QA Engineer 使用本模板自行判断测试环境和测试流程是否达到团队可用程度。

## 必须说明

- 测试范围和需要验证的核心行为；
- 选择本地测试环境还是线上测试环境，以及选择理由；
- 测试环境的构建、启动和停止方式；
- Backend 和 Frontend 如何运行；
- 需要的账号、测试数据、API Key 和外部服务；
- 功能测试、回归测试和必要专项测试的执行方式；
- 如何收集日志、截图、录屏、测试报告或其他证据；
- 环境不可用或测试失败时如何区分产品、测试和环境问题。

## 合格标准

另一个 QA Engineer 可以只读取本文档，在不依赖口头说明的情况下构建合适的测试环境并开始验证。

默认优先选择简单、方便、能够覆盖目标的本地测试方式。线上环境只有在产品行为或外部集成确实需要时才使用。
