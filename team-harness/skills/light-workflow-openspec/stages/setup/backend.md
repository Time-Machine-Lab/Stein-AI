# Setup：Backend

**负责人：** Backend Engineer

1. 确认项目需要 Backend，且技术栈已经确定；未确定时暂停，不进入下一步。
2. 读取 [backend-development.md](../../document-standards/backend-development.md)。
3. 按已确定的技术栈，只初始化后端工程目录和必要配置骨架。
4. 不实现任何产品功能、业务逻辑、API 或测试。
5. 生成 `tml-docs/backend-development.md`，说明本项目的技术栈、文件树、目录职责和模块边界。
6. 自行确认工程结构与文档一致后通知 Delivery Manager。
