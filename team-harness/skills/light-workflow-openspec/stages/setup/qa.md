# Setup：QA

**负责人：** QA Engineer

1. 读取 [qa-test-environment.md](../../document-standards/qa-test-environment.md)。
2. 选择最简单且能覆盖目标的测试方式，默认优先本地测试。
3. 记录测试环境构建、启动、测试数据、外部服务和测试流程。
4. 将文档保存为 `tml-docs/qa-test-environment.md`。
5. 缺少账号、API Key 或其他资源时通知 Delivery Manager，不得编造凭据。
6. 自行确认文档可执行后通知 Delivery Manager。
